# 基于状态感知双粒度关系对齐的扩散零样本学习

## 一 文章主线

核心问题：类别语义与实例表征提供了互补的关系知识，但将二者作为生成条件，是否足以使生成特征保留跨类相对结构和类内实例差异？

全文围绕“条件信息如何转化为生成特征中的关系保持”展开。ZeroDiff提供条件扩散生成基础；本文进一步研究跨类语义关系与类内实例关系的显式迁移，并结合扩散输入状态组织关系监督。

论证顺序：已有条件生成进展 → 两类条件包含互补关系知识 → 条件使用与关系保持之间仍需建立显式联系 → 按粒度与状态构建关系监督 → 检查关系是否改善以及识别是否受益。

主要定位是双粒度关系保持。扩散状态用于控制比较条件和组织监督贡献，不预先将“实例可靠性随噪声下降更快”作为已证实的规律。

## 三 问题定义与理论分析

### 3.1 两种可观察关系偏差

- 跨类相对结构偏移：生成特征的跨类相对距离或远近排序，相对于类别语义参照发生偏移。
- 类内实例关系失真：同类不同实例之间的相对距离或排序，相对于实例对比表征参照发生变化。

关系保持指对指定参考知识中有用结构的保持。语义与视觉并非天然等距空间，非零差异不能全部归因于生成错误。采用真实视觉特征与相同参照的关系作为经验对照，再考察生成过程额外引入的偏差；真实视觉结果不是理论下界。

### 3.2 分析一 类别可分性不足以确定关系几何

可用简单构造说明：三个语义参照为 a_A=0、a_B=1、a_C=3；三个生成类中心为 g_A=0、g_B=3、g_C=1。各类别仍可正确区分，但A到B、C的距离排序反转。该例说明仅凭类别可分性或分类结果，无法认定跨类参考几何被保持。

这是一项逻辑上的非蕴含分析，不是对ZeroDiff实际失真的证明，也不说明其全部生成目标对任意几何变换保持不变。若生成分布精确匹配真实条件分布，其相应分布几何也会被恢复；本文关注有限数据和实际优化下，是否需要增加相对于指定参照的显式关系约束。

### 3.3 分析二 类别语义缺少类内关系信息

同类实例共享语义原型：y_i=y_j意味着a_i=a_j，进而语义距离为零。类别语义因此不能单独提供非平凡的类内实例参照；若直接匹配所有样本对的语义距离，同类对会受到收缩压力。这解释了为何跨类关系采用语义参照、类内关系采用实例对比参照。

实例对比表征是否含有可迁移的有用关系，需要通过类内关系指标和移除实例约束的实验检验。RSC校准是否保留了这些关系，也应检查，不由校准损失下降直接推断。

### 3.4 分析三 扩散状态控制比较条件

不同状态下预测目标均为清洁特征，但输入信号保留率不同，因此预测误差分布可能不同。同状态对齐的作用是控制关系比较的噪声条件；它不保证各实例预测误差相同，也不是跨时间步输出相等约束。

信号保留率可用于参数化状态分配，但不能直接证明两类关系应采用不同权重、实例权重必须衰减更快，或某条幂函数等于监督可靠性。GSR的价值及调度方向通过受控对照检验。

理论分析可在方法开头或补充材料完整展开。Introduction只保留支撑问题的简短逻辑，不堆叠推导。

| 研究问题 | 最小对照与证据 |

| 条件输入是否已足以保留关系 | 真实视觉与ZeroDiff相对于固定参考的关系指标，考察生成额外偏差 |

## 附录 现有方法公式备忘

以下保留原大纲中的方法定义与公式，供写作核对。本轮未据此修改初稿的方法章节；旧逐状态诊断描述不再作为动机依据。

### 3.1 问题设定

零样本学习包含互不相交的已见类别集 \(\mathcal Y^s\) 与未见类别集 \(\mathcal Y^u\)，即 \(\mathcal Y^s\cap\mathcal Y^u=\varnothing\)。训练集为 \(\mathcal D_{\mathrm{tr}}=\{(x_i,y_i,\boldsymbol a_i)\}_{i=1}^{N_s}\)，其中 \(N_s\) 为样本数，\(x_i\in\mathcal X^s\) 为已见类图像，\(y_i\in\mathcal Y^s\) 为标签，\(\boldsymbol a_i=\boldsymbol a_{y_i}\) 为类别语义。未见类语义可用于生成，其真实图像不参与训练。传统ZSL的目标是学习分类器 \(f_{\mathrm{ZSL}}:\mathcal X^u\rightarrow\mathcal Y^u\)；GZSL还需识别未参与训练的已见类样本，目标为 \(f_{\mathrm{GZSL}}:\mathcal X^s\cup\mathcal X^u\rightarrow\mathcal Y^s\cup\mathcal Y^u\)（Chen等，2025；Ye等，2025）。

### 3.2 状态感知双粒度关系对齐

我们在ZeroDiff的基础生成训练中引入状态感知双粒度关系对齐，由关系空间校准（RSC）、同状态双粒度关系对齐（SDGA）和粒度感知状态重加权（GSR）组成，分别建立关系比较空间、确定粒度与状态内的对齐范围，并调节状态监督贡献。

#### 3.2.1 关系空间校准

视觉与对比表征由不同学习目标塑造，其原始关系几何未必适合直接监督生成。距离归一化可以调整整体尺度，却不能自动消除结构偏差。为此，关系空间校准（Relational Space Calibration，RSC）利用真实已见类数据学习关系投影，为后续生成关系约束建立比较基础。

记样本 \(i\) 的清洁视觉特征、实例对比表征与类别语义为 \(\boldsymbol v_{0,i}\)、\(\boldsymbol r_{0,i}\) 和 \(\boldsymbol a_i=\boldsymbol a_{y_i}\)。投影器得到 \(\boldsymbol u_i=E_v(\boldsymbol v_{0,i})\) 与 \(\boldsymbol h_i=E_r(\boldsymbol r_{0,i})\)，并对输出进行 \(\ell_2\) 归一化。我们以归一化距离描述样本间的相对分离，以三元组方向描述围绕共同中心的相对布局。对于批次表示 \(H=\{\boldsymbol h_i\}_{i=1}^{N}\)，令 \(d_{ij}(H)=\|\boldsymbol h_i-\boldsymbol h_j\|_2\)，定义

\[
\begin{aligned}
\widehat d_{ij}(H)
&=\frac{d_{ij}(H)}{\max(\mu(H),\epsilon)},\\
\mu(H)
&=\frac{1}{|\mathcal E_H^{+}|}
\sum_{(i,j)\in\mathcal E_H^{+}}d_{ij}(H),\\
\psi_{ijk}(H)
&=\left\langle
\frac{\boldsymbol h_i-\boldsymbol h_j}{\max(d_{ij}(H),\epsilon)},
\frac{\boldsymbol h_k-\boldsymbol h_j}{\max(d_{kj}(H),\epsilon)}
\right\rangle.
\end{aligned}
\]

其中，\(\mathcal E_H^{+}=\{(i,j):i\ne j,\ d_{ij}(H)>0\}\)，\(\epsilon>0\) 为数值稳定常数；无非零距离时归一化尺度取1。对于两组具有样本对应关系的表示 \(P\) 和 \(Q\)，分别在样本对与三元组上平均匹配关系：

\[
\begin{aligned}
\mathcal L_d(P,Q)
&=\frac{1}{N^2}\sum_{i,j=1}^{N}
\ell_{\mathrm{SL1}}\!\left(
\widehat d_{ij}(P)-\widehat d_{ij}(Q)\right),\\
\mathcal L_a(P,Q)
&=\frac{1}{N^3}\sum_{i,j,k=1}^{N}
\ell_{\mathrm{SL1}}\!\left(
\psi_{ijk}(P)-\psi_{ijk}(Q)\right).
\end{aligned}
\]

其中，\(\ell_{\mathrm{SL1}}\) 为Smooth L1函数。记统一关系目标为 \(\mathcal R(P,Q)=\lambda_d\mathcal L_d(P,Q)+\lambda_a\mathcal L_a(P,Q)\)，\(\lambda_d\) 与 \(\lambda_a\) 控制距离与方向的贡献，第二个变量作为停止梯度的参照。

令真实视觉投影、对比投影与类别语义的批次表示为 \(U\)、\(H\) 和 \(A\)，校准目标为

\[
\mathcal L_{\mathrm{RSC}}
=\eta_1\mathcal R(U,A)
+\eta_2\mathcal R\bigl(U,\operatorname{sg}(H)\bigr)
+\eta_3\mathcal R(H,A).
\]

其中，\(\operatorname{sg}(\cdot)\) 表示停止梯度，\(\eta_1,\eta_2,\eta_3\geq0\) 为校准系数。视觉投影同时匹配语义与对比关系，对比投影接受语义锚定；第二项不更新 \(E_r\)。同类语义重合会使第三项对类内相对距离产生收缩压力，\(\eta_3\) 调节这一锚定强度。

#### 3.2.2 同状态双粒度关系对齐

同状态双粒度关系对齐（State-Matched Dual-Granularity Alignment，SDGA）将关系划分为类别级（C）与实例级（I）：类别级关系比较不同类别的样本，以类别语义为参照；实例级关系比较同类的不同实例，以实例对比表征为参照。两种粒度分别对应跨类结构与类内结构。

“同状态”指关系对中的生成预测使用相同的扩散输入时间步，即 \(t_i=t_j\)。不同状态的预测虽以清洁特征为目标，其误差特性仍可能不同，因此将关系限定在状态内部计算。对于分配至生成步 \(t_i\) 的样本 \(i\)，定义

\[
\begin{aligned}
\widetilde{\boldsymbol v}_{0,i}^{(t_i)}
&=G\left(\boldsymbol z_i,\boldsymbol a_i,\boldsymbol r_{0,i},
\boldsymbol v_{t_i+1,i},t_i\right),\\
\widetilde{\boldsymbol u}_i^{(t_i)}
&=E_v\left(\widetilde{\boldsymbol v}_{0,i}^{(t_i)}\right).
\end{aligned}
\]

其中，\(t_i\in\{0,\ldots,T-1\}\)，输入为 \(\boldsymbol v_{t_i+1,i}\)，\(\boldsymbol z_i\) 为潜变量，上标 \((t_i)\) 标记预测所依赖的状态，输出仍为清洁特征。类别语义 \(\boldsymbol a_i\) 与对比投影 \(\boldsymbol h_i\) 保持为清洁参照；各实例使用独立噪声，同状态不要求噪声实现相同。状态 \(t\) 下的两组关系对为

\[
\begin{aligned}
\mathcal P_C(t)&=\{(i,j):t_i=t_j=t,\ y_i\ne y_j\},\\
\mathcal P_I(t)&=\{(i,j):t_i=t_j=t,\ y_i=y_j,\ i\ne j\}.
\end{aligned}
\]

跨类分离与类内差异具有不同尺度，共用归一化尺度会使两类关系相互影响。我们因此按粒度与状态分别归一化，并为生成表示和参考表示各自计算尺度。对于 \(g\in\{C,I\}\)，定义

\[
\widehat d_{ij}^{\,g,t}(H)
=\frac{d_{ij}(H)}{\max(\mu_{g,t}(H),\epsilon)},
\qquad
\mu_{g,t}(H)
=\frac{1}{|\mathcal P_g^{+}(t;H)|}
\sum_{(i,j)\in\mathcal P_g^{+}(t;H)}d_{ij}(H),
\]

其中，\(\mathcal P_g^{+}(t;H)\) 为 \(\mathcal P_g(t)\) 中距离为正的样本对集合，空集合沿用RSC的尺度约定。令 \(\widetilde U\) 为当前批次的生成视觉投影，状态损失为

\[
\begin{aligned}
\mathcal L_C(t)
&=\frac{1}{|\mathcal P_C(t)|}
\sum_{(i,j)\in\mathcal P_C(t)}
\ell_{\mathrm{SL1}}\!\left(
\widehat d_{ij}^{\,C,t}(\widetilde U)-\widehat d_{ij}^{\,C,t}(A)
\right),\\
\mathcal L_I(t)
&=\frac{1}{|\mathcal P_I(t)|}
\sum_{(i,j)\in\mathcal P_I(t)}
\ell_{\mathrm{SL1}}\!\left(
\widehat d_{ij}^{\,I,t}(\widetilde U)-\widehat d_{ij}^{\,I,t}(H)
\right).
\end{aligned}
\]

两类损失分别约束跨类语义结构与类内实例结构。参考关系停止梯度，生成距离及其归一化尺度参与反向传播。RSC在真实批次上利用距离与方向共同校准比较空间；SDGA的监督范围由两类样本对确定，因此生成阶段采用相对距离实施粒度分工，不额外构造各状态的三元组约束。

为提供有效关系对，训练采用 \(P\times K\) 类别均衡采样，并按类别分配时间步，使同类实例共享状态、各状态包含多个类别，每类包含不同实例。记 \(\mathcal T_g=\{t:|\mathcal P_g(t)|>0\}\) 为有效状态集合，各状态先平均样本对损失，再进行状态聚合，以区分关系对数量与状态贡献。

#### 3.2.3 粒度感知状态重加权

粒度感知状态重加权（Granularity-Aware State Reweighting，GSR）依据输入信号保留率，为两类关系设置可调的状态敏感性。考虑到类内关系涉及细粒度变化，我们将低信号状态下更谨慎地分配实例级监督作为候选设计，其方向需要与固定、共享及反向差异化调度对照检验。

生成步 \(t\) 的输入为 \(\boldsymbol v_{t+1}\)，以 \(s_t=\bar\alpha_{t+1}\) 表征其信号保留率，其中 \(\bar\alpha\) 为扩散日程的累计信号系数。相较线性时间步索引，该量直接对应实际日程中的信号变化。对于 \(g\in\{C,I\}\)，采用可调幂函数构造权重：

\[
a_g(t)=f+(1-f)s_t^{p_g},
\qquad
w_g(t)=\frac{a_g(t)}{\frac{1}{T}\sum_{\tau=0}^{T-1}a_g(\tau)}.
\]

其中，\(0<f\leq1\) 保留高噪声状态的监督，\(p_g\geq0\) 调节衰减曲线。设置 \(p_I>p_C\) 且 \(f<1\)，会使实例级原始权重在中低信号状态下衰减得更快。完整日程归一化使每种粒度的权重均值为1，从而将状态分配 \(w_g(t)\) 与粒度强度 \(\lambda_C,\lambda_I\) 区分开；原始权重的跨粒度大小关系不必在归一化后逐点保持。共享指数对应共享调度，零指数恢复等权监督。

重加权后的粒度损失及联合生成目标为

\[
\begin{aligned}
\mathcal L_g^{\mathrm{GSR}}
&=\frac{1}{\max(1,|\mathcal T_g|)}
\sum_{t\in\mathcal T_g}w_g(t)\mathcal L_g(t),\\
\mathcal L_{\mathrm{GSR}}
&=\lambda_d\left(
\lambda_C\mathcal L_C^{\mathrm{GSR}}
+\lambda_I\mathcal L_I^{\mathrm{GSR}}
\right),\\
\mathcal L_G
&=\mathcal L_{\mathrm{base}}
+\gamma_{\mathrm{rel}}\mathcal L_{\mathrm{GSR}}.
\end{aligned}
\]

其中，\(\lambda_C,\lambda_I\geq0\) 分别控制两种粒度的监督强度，\(\gamma_{\mathrm{rel}}\geq0\) 控制关系监督的整体贡献，\(\mathcal L_{\mathrm{base}}\) 沿用ZeroDiff的基础生成目标。权重始终按完整日程归一化，损失按有效状态数聚合，不依据当前批次的权重和重新归一化。

### 3.3 整体概述

训练时，先利用真实已见类批次更新关系投影器，再固定其参数，以关系目标与基础生成目标联合更新视觉生成器；关系梯度仍可经 \(E_v\) 传回生成器，基础判别器按原有目标更新。训练完成后，冻结扩散表征生成器 \(G_r^{*}\) 与视觉特征生成器 \(G^{*}\)。推理时，\(G_r^{*}\) 根据未见类别语义合成对比表征，\(G^{*}\) 进一步以类别语义和合成表征为条件生成视觉特征，随后利用合成数据训练轻量分类器完成零样本识别。
