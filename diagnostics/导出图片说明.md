# 诊断导出图片说明

## 1. 文件与论文排版

运行 `python -m diagnostics.run_baseline` 后，默认在 `out/diagnostics/<数据集>/` 导出：

| 文件名 | 内容 |
| --- | --- |
| `diagnosis_a_relation_error.png` | 关系距离对齐误差，数值越低表示越接近参考关系 |
| `diagnosis_b_rank_agreement.png` | 关系距离的 Spearman 秩相关，数值越高表示排序越一致 |
| `diagnosis.png` | 上述两幅图的左右合并图 |
| `metrics_seed_<seed>.csv` | 每个 episode、每个扩散时间步的原始指标及运行信息 |

使用 `--output-dir` 可以指定导出目录。三幅图均按 240 dpi 导出。

为便于插入论文，导出图片不显示总标题 `Frozen ZeroDiff: dual-granularity relation diagnostics`，也不显示 `(a) Relation alignment error`、`(b) Relation rank agreement` 子图标题。论文中的图号、子图标记和说明可由排版系统统一添加。

横轴仅保留 `Diffusion timestep t` 与实际时间步的整数刻度，例如 `0、1、2、3`。不再显示 `signal retention alpha_bar[t+1]`，也不显示 `0.522、0.079、0.003、0.000` 等第二行刻度。纵轴、图例、曲线和阴影保留。`signal_retention` 与 `snr` 仍记录在 CSV 中，便于复核。

此次修改作用于绘图代码。已有 PNG 需要重新绘制才会更新；若保留了原始 CSV，可直接调用 `plot_diagnosis` 重绘，无需重新推理模型。聚合多个 CSV 时，应使用同一数据集、同一 checkpoint 和相同采样配置的数据。

## 2. 诊断对象与横轴含义

诊断代码加载未启用关系约束的 ZeroDiff 基线 checkpoint，并在不更新模型的情况下测量关系保持情况。每个 episode 从训练集已见类中抽取 `ways` 个类别，每类抽取 `shots` 个样本。

对同一个 episode，各时间步使用相同样本、潜变量和高斯噪声，以便配对比较。横轴 `t` 是输入生成器的扩散时间步，默认四步时为 `0、1、2、3`，不是训练轮数。代码在每个 `t` 下构造加噪输入 `x_{t+1}`，再预测干净视觉特征 `x_0`，分别计算诊断指标；这些点不是一次连续反向采样轨迹上的中间结果。

原图第二行数值表示输入 `x_{t+1}` 的信号保留率 `alpha_bar[t+1]`。其值越小，输入中的原始信号占比越低；图中的 `0.000` 是保留三位小数后的显示值，不必然等于严格的零。

## 3. 蓝色与红色曲线

| 图例 | 样本对范围 | 比较对象 |
| --- | --- | --- |
| 蓝色 `Cross-class semantic` | 标签不同的样本对 | 生成视觉特征的距离与对应类别语义属性的距离 |
| 红色 `Within-class PaCo` | 同类且非自身的样本对 | 生成视觉特征的距离与对应真实 PaCo 对比特征的距离 |

这里的“跨类关系”使用跨类样本对，并不是先计算类别中心再比较。两条曲线使用不同的参考特征和样本对集合。

距离由欧氏距离计算。对每种关系，生成特征距离和参考特征距离分别除以各自所选距离中的正值均值，再进行比较，因此指标主要反映相对距离结构，而非原始特征尺度。

## 4. 图 (a)：关系距离对齐误差

纵轴为 `Normalized distance error (Smooth L1)`。代码对归一化后的生成距离与参考距离计算平均 Smooth L1 损失：越低表示相对距离越接近，零表示所比较的归一化距离完全一致。

就所提供的截图而言，蓝线约为 `0.016–0.017`，随 `t` 增大略降；红线约为 `0.049–0.050`，略升后趋于平缓。这说明在这次诊断配置下，两种关系的误差随时间步变化较小，类内 PaCo 关系的归一化距离误差高于跨类语义关系。以上数值来自截图目测，论文中的精确数值应以 CSV 为准。

由于两条曲线对应的参考空间和样本对集合不同，仅凭红线高于蓝线，不能直接认定某个模块失效，也不能将误差差值换算为分类准确率差异。跨时间步的细小变化是否显著，需要结合配对数据进一步分析。

## 5. 图 (b)：关系排序一致性

纵轴为 `Spearman correlation (higher is better)`。代码比较同一批样本对在生成特征空间和参考特征空间中的距离排序，取值范围为 `[-1, 1]`：接近 `1` 表示排序较一致，接近 `0` 表示单调排序关系较弱，接近 `-1` 表示排序方向相反。

图 (a) 关注相对距离数值是否接近，图 (b) 关注远近次序是否一致，二者应结合解读。距离误差较低并不保证排序相关性一定较高。

若参与比较的距离为常数，或可用距离数量不足，Spearman 相关系数记为 `NaN`。汇总时会排除非有限值，因此相关性曲线某个点的有效 episode 数可能少于误差曲线。实际趋势和数值需查看导出的图 (b) 或对应 CSV；本次提供的截图仅包含图 (a)。

## 6. 圆点、连线与阴影

每个圆点是该时间步所有有效 episode 指标的算术均值，连线用于展示时间步之间的变化。半透明阴影为“均值 ± 样本标准差”，标准差采用 `ddof=1`。它描述 episode 间的波动，不是标准误或置信区间；只有一个有效值时，代码将标准差记为零。

导出时会合并同一目录中与当前数据集、checkpoint 哈希、`split_percent`、`ways` 和 `shots` 匹配的 `metrics_seed_*.csv`。每个有效 episode 等权参与汇总，并非先对每个种子取均值再等权平均。重新运行相同种子会替换该种子的 CSV；不同种子的 CSV 可以共同参与绘图。

## 7. 论文图注参考

> 冻结 ZeroDiff 基线在不同扩散时间步下的双粒度关系诊断。（a）归一化关系距离的 Smooth L1 误差，越低越好；（b）关系距离的 Spearman 秩相关系数，越高越好。蓝色表示跨类视觉关系与语义关系的比较，红色表示类内视觉关系与 PaCo 对比特征关系的比较。圆点表示 episode 均值，阴影表示均值上下一个样本标准差。同一 episode 在各时间步共享样本、潜变量与高斯噪声。

使用时应在正文或图注中补充实际数据集、checkpoint、`ways`、`shots`、episode 数、诊断种子及潜变量来源；这些信息可从运行参数和 CSV 记录中核对。
